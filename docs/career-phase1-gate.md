# Career Dashboard — Phase 1 gate (review at 4 weeks)

## Success criteria (§1.1)

- [ ] **(a) Voluntary weekly use** — dashboard opened and reviewed ≥once/week with authentic engagement (not just a load)
- [ ] **(b) Brag log materially shortened review-cycle prep** — documented evidence that weekly brag/work-log entries reduced time or complexity in performance reviews
- [ ] **(c) ≥1 Focus recommendation changed what I actually worked on this month** — at least one heuristic focus item influenced real task selection or approach

## Evidence definition

**Acted-on evidence at this gate** = a ticket picked up (or task approach followed), traceable to a specific Focus item via its acted-on mark (stored in `career.json.focusActed`). The signal is direct: the item was reviewed in the dashboard and then marked as acted-upon, with a corresponding real-world action logged in the task board or session log.

---

**If (a)–(c) are not met, stop and reassess before Phase 2.**
